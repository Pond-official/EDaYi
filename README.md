# EDaYi（E大医）

> 面向大连医科大学的 HarmonyOS 原生一站式校园助手。
> 课表、成绩、综合测评、选课、培养计划、期末倒计时、上课提醒、一卡通余额、图书借阅、桌面卡片，一个应用全搞定。

当前版本：**3.7.6**（versionCode 3070006）

## 功能一览

| 模块 | 说明 |
|---|---|
| 首页 | 今日课程、周课表任意周次查看（整学期离线缓存，标题栏胶囊可下拉选周）、学生信息、一卡通余额与借阅数量小卡、期末倒计时（按科目，不足一天显示小时）、应用日志（开发者选项） |
| 成绩 | 学分绩点汇总卡、学期筛选、分类成绩分组、培养计划入口、成绩替代行解析（TDKCM） |
| 综评 | 批次上下文卡、素质得分多维图（雷达图）、指标分级展开（多条同时展开、收起仅由行头触发，未登录展示去登录引导）、附加分明细、平板横屏双列布局 |
| 选课 | 独立选课账号、轮次切换、课程检索、提交选课、已选查询，凭据加密存储 |
| 图书借阅 | 当前借阅（应还日期、逾期标记、一键续借）与借阅历史，支持下拉刷新；每次进入实时拉取 |
| 期末倒计时 | 按科目设置考试时间（精确到分钟，可从培养计划补录考查课）；可经系统分享面板发给其他设备，也能接收他人分享的考试时间一键导入 |
| 设置 | 上课提醒（系统通知 / 日历代理可选）、桌面课表小卡（到点后自动显示明日课程，时间可自定义）、个性化背景（跟随系统 / 纯白 / 图库图片）、隐私三档（标准 / 限制 / 严格）、缓存清理、关于 |
| 桌面卡片 | 课表卡片（今天 / 明天、单周 / 双周，按周一锚点自动推进周次）、多科目期末倒计时卡片，无需打开应用即可查看 |

## 技术栈

- **HarmonyOS** / ArkTS / ArkUI（Stage 模型）
- **hvigor** 构建体系，**hypium** 单元测试（107 用例）
- 原生能力：Asset 凭据存储、通知 / 代理提醒、日历读写、服务卡片 Form、ArkWeb 隐藏页面换票、跨域 SSO 会话、Share Kit 系统分享、图库选图
- 冷启动优化：非首屏模块按需加载、登录后并行预载、Web 宿主延迟挂载
- 动画：卡片级联上滑入场（360ms EaseOut 错峰）、全页滚动回弹、页签切换渐入
- 适配手机 / 折叠屏 / 平板，横屏双列布局，深浅色主题跟随系统

## 快速开始

1. 安装 [DevEco Studio](https://developer.huawei.com/consumer/cn/deveco-studio/)（含 HarmonyOS SDK）。
2. 导入本仓库根目录，等待 hvigor 同步。
3. 连接模拟器或真机，点击运行；或使用命令行：

```powershell
# 构建
devecocli build

# 部署到已连接设备（跳过构建）
devecocli run --skip-build --device <deviceId>
```

首次使用需在应用内登录学校统一认证，之后凭据按隐私模式本地加密存储。

> 仓库不含本地签名配置（`build-profile.json5` 中的 signingConfigs），克隆后需在 DevEco Studio 的 Project Structure → Signing Configs 中自行配置签名才能安装到设备。

## 应用数据获取流程

学校的几套业务系统（教务、学工、门户、图书馆、选课）分散在不同域名，认证方式也不完全一致。应用按下面的链路逐个打通，除选课外全部复用同一份 CAS 登录态。

### 1. 统一认证登录（CAS）

首次使用时在应用内打开教务系统首页，会自动 302 跳转到学校统一认证。输入学号密码后，CAS 带着票据重定向回教务域，会话 Cookie 落入系统 Cookie 存储。登录页检测到 URL 回到教务域，便调用会话探针（`currentUser.do`，`code == "0"` 视为有效），随后自动进入应用。

### 2. 教务数据（jwxt.dmu.edu.cn）

请求全部走原生 HTTP（`postForm` / `getForm`），每次从系统 Cookie 读取教务会话并附加到请求头。课表、成绩、学生信息、当前学期、培养计划等 `.do` 接口返回 JSON 或 HTML，统一由 `jwxt/parsers` 解析成强类型模型。

### 3. 跨域会话：换票（CrossDomainSession）

综评、门户、图书馆分属不同域名，仅有一次 CAS 登录并不能直接访问——每个域都要先「换一次票」，把 CAS 登录态兑换成该域自己的会话 Cookie。

做法是：根页面按需挂载一个 1×1 的隐藏 Web，静默加载目标域入口页，由 WebView 走完 CAS 的单点重定向链，Cookie 随之落入系统存储。不同域排队串行执行；引导过程中若落到 CAS 登录页，判定为会话过期；超时按失败返回，由界面提示重新登录。

### 4. 一卡通余额与借阅数量（ehall 门户）

换票完成后先加载门户页停留 15 秒做「预热」，让页面脚本触发服务端的数据聚合。随后调用「个人数据」聚合卡片端点（`execCardMethod`），按条目 wid 分别取一卡通余额与图书借阅数量。若服务端尚未聚合完成（`data: null`），以 1.5 秒间隔轮询，最多 6 次。

### 5. 综合测评（xgfw.dmu.edu.cn）

换票建立 xgfw 会话后，原生接口先切换学生角色，再依次拉取批次上下文、综测得分、指标明细与附加分明细。

### 6. 图书借阅（汇文 LibSP）

隐藏 Web 走 CAS → 超星 CAS → LibSP 的 SSO 链，换取 JWT 落在 Cookie 中。原生接口凭该 JWT 拉取当前借阅与借阅历史，并支持一键续借。令牌 24 小时内有效且不提供刷新，过期后自动重新换票。

### 7. 选课（jwxk.dmu.edu.cn）

选课系统不走 CAS，需独立账号原生登录：密码 AES 加密后提交，配合图形验证码。登录 token 只存在内存、永不持久化；凭据由系统 Asset 加密保存，可在设置中一键清除。

## 隐私与安全设计

- **隐私三档模式**：标准（全量离线缓存）/ 限制（仅课表缓存）/ 严格（不缓存任何信息，退出即清理并登出）；
- **凭据**：选课账号密码由系统 **Asset** 加密保存，登录 token 只存在于内存；教务及各域会话 Cookie 交由系统 Cookie 存储管理；
- **本地缓存静态加密**：离线缓存（含学生信息/成绩）与综测、一卡通缓存文件经系统密钥库（HUKS）包装的数据密钥 AES-256-GCM 加密后落盘；换机恢复备份或密钥被卸载时旧密文不可恢复，按空缓存重新同步，绝不回退明文存储；课表卡片数据为高频同步读路径，保持明文以加快启动与卡片刷新；
- **离线缓存归属校验**：缓存记录归属学号与会话标识，回放前校验——换账号登录或退出登录后不再回放上一账号的离线数据，宁可空态提示重新登录；
- **不落盘的数据**：图书借阅明细与综测评分明细仅存在于内存，JWT 随进程结束失效，每次进入页面重新拉取；
- **离线态可感知**：数据来自离线缓存时页面顶部显示醒目横幅，可一键重登或重试刷新；
- **本地背景**：从图库选择的背景图复制到应用沙箱保存，仅用于渲染页面，不会上传；
- **分享内容克制**：分享出去的只有课程名与考试时间，不含学号、成绩等个人信息；严格隐私模式下导入的考试时间不落盘；
- **日志**：应用内行为日志仅存内存环形缓冲，随进程销毁，不写入磁盘。

- **3.1.0**：期末倒计时重构——设置页新增独立「期末倒计时」二级页，按科目设置考试时间（`YYYY-MM-DD HH:mm`，精确到分钟），可从本学期培养计划补录考查课等非考试科目；倒计时支持分钟级目标时间，剩余不足一天时显示小时；宽屏布局下倒计时卡移至左列；新增日期工具单元测试，用例数 52 → 62。
- **3.0.0**：可维护性重构——拆分解析器 / 网络层 / 缓存 / 隐私控制 / 会话仓库，视图层按页拆分为 Cards 构建器；新增状态键契约校验脚本与 52 个单元测试；页面支持左右滑动切换；成绩替代行解析适配新格式。
