# 开发规范（提交前必读）

本项目为纯本地开发（无远端 CI），所有提交前校验通过本地一条命令完成。

## 提交前校验（一条命令）

```powershell
powershell -ExecutionPolicy Bypass -File scripts\verify.ps1
```

该脚本按顺序执行三道关卡，任一关卡失败即非 0 退出（fail-fast）：

| 关卡 | 内容 | 判定 |
|---|---|---|
| 1/3 | 状态键契约校验（`node tools/check_storage_keys.mjs`） | 出现未登记/类别不符的状态键即失败 |
| 2/3 | DevEco Code Linter（配置 `code-linter.json5`） | 出现 **Error** 级问题即失败；Warning 仅报告不拦截 |
| 3/3 | 单元测试（hypium，Pond 模块，当前 48 用例） | `Failure/Error` 非 0 或未全过即失败 |

各关卡也可单独执行：

```powershell
# 状态键契约校验
node tools\check_storage_keys.mjs

# Code Linter（表格报告）
devecocli check lint

# 单元测试
& "C:\Program Files\Huawei\DevEco Studio\tools\node\node.exe" `
  "C:\Program Files\Huawei\DevEco Studio\tools\hvigor\bin\hvigorw.js" `
  --mode module -p product=default -p module=Pond@default test
```

## 状态键契约（任务 11）

- `@StorageProp` / `@StorageLink` / `@LocalStorageProp` 的装饰器参数**必须是字符串字面量**
  （ArkUI 限制，传常量编译不通过），因此状态键无法收口为常量。
- 全部 38 个状态键登记在 `products/Pond/src/main/ets/constants/StorageKeys.ets`
  （23 个 AppStorage 键 + 15 个卡片 LocalStorage 键），每条注明类型 / 写入方 / 读取方。
- **新增 / 改名状态键**：先在 `constants/StorageKeys.ets` 按格式登记
  （`// [AppStorage] 键名 | ...` 或 `// [LocalStorage] 键名 | ...`），再写装饰器；
  否则 `tools/check_storage_keys.mjs` 与 `scripts/verify.ps1` 会直接报错。

## 颜色规范（任务 10）

- 视图 / 页面 / 卡片层**禁止新增硬编码 hex**（`'#RRGGBB'`）。
- 颜色统一使用 `products/Pond/src/main/ets/theme/AppColors.ets` 的具名常量；
  新语义色先在该文件登记（命名体现语义而非色值），再引用。
- 不使用 `$r('app.color.x')`：`ZcpRadarChart` 的 Canvas 绘制与卡片侧取不到资源解析值，
  代码常量是唯一可行方案。

## Code Linter 已知基线（脚本白名单）

`scripts/verify.ps1` 的 `$KnownLintErrors` 白名单登记了当前唯一一条 Error 级已知问题：

- `data/ReminderScheduler.ets` `@typescript-eslint/await-thenable`（245 行）：
  `notificationManager.requestEnableNotification` 在 SDK 中为回调+Promise 双重载，
  eslint 解析时命中 void 重载导致误报，`await` 写法本身有效（官方文档即此用法）。
  **已记录不修**（工单铁律：发现 bug 只记录不修，且此条非 bug 为误报）。
- 白名单仅此一条；向白名单追加条目必须在本文档写明理由。

## 其他约定

- ArkTS 严格模式：禁 `any` / `unknown` / 索引签名 / 结构化类型，对象字面量必须有显式类型。
- 禁止用 PowerShell 的 `Get-Content`/`Set-Content` 读写含中文的 `.ets` 源文件
  （PS 5.1 默认 GBK 会损坏 UTF-8 文件），请使用编辑器或 UTF-8 安全的工具。
- 每次功能改动需保证 `devecocli build` 成功、48 个单测全绿后再提交。
